# Ramaldi dentro del diseño oscuro

La integración conserva el fondo carbón, superficies oscuras, Inter y composición de Claude. Las dos imágenes del logo Ramaldi compartidas por el propietario orientan los acentos de marca; no se ha redibujado el símbolo ni inventado una identidad nueva.

| Uso actual | Variable CSS | Color |
| --- | --- | --- |
| Fondo de Claude | `--bg` | `#2B2B2B` |
| Superficies | `--bg-raised` / `--bg-deep` | `#333333` / `#222222` |
| Texto principal | `--text` | `#FFFFFF` |
| Verde de referencia del logo | `--petroleum` | `#437976` |
| Verde profundo para CTA contextual | `--petroleum-deep` | `#285651` |
| Texto de marca sobre carbón | `--brand-ink` | `#ACD7CF` |
| Dorado de referencia / claro | `--gold` / `--gold-light` | `#DEA900` / `#F5E8B3` |
| Acento de demostración conservado de Claude | `--accent` | `#C9A96A` |

Los tonos de Ramaldi se aproximan visualmente a las imágenes recibidas; no son códigos corporativos certificados. El verde claro es una variante para lectura sobre carbón. El dorado claro acentúa la etiqueta del alquiler; el verde identifica su renta pendiente y CTA móvil. No se sustituye el fondo general ni la familia tipográfica.

Contraste calculado mediante luminancia relativa sRGB y fórmula WCAG: verde claro/carbón **9,02:1**, dorado claro/carbón **11,51:1**, blanco/verde profundo **8,27:1**. Son pares sólidos; no certifican por sí solos todos los textos sobre fotografías o degradados. La revisión actual y sus límites están en AUDIT-INTEGRATION.md.

El checkout aún no contiene un archivo original reutilizable del logo. El encabezado conserva la identidad tipográfica de Claude y el retrato sigue pendiente. No se usan otras empresas llamadas Ramaldi como referencia corporativa.
