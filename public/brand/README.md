# Recursos oficiales pendientes

Este directorio espera los dos logotipos originales proporcionados por el propietario.
No se han recibido en esta sesión. No se ha creado un logotipo corporativo alternativo.

Cuando estén disponibles:

1. Conservar archivos originales autorizados (SVG preferido, o PNG transparente).
2. Añadirlos a este directorio con nombres claros.
3. Configurar `site.logo` en `src/lib/site.ts` y ajustar el tamaño del encabezado si es necesario.
4. Comprobar que el nombre de Thony sigue visible, que la imagen no se deforma y que el contraste es correcto.
5. Para la fotografía de Thony, añadir el archivo autorizado a `public/images/` y configurar `site.portrait`.

El monograma de la pestaña y el texto del encabezado son recursos tipográficos provisionales, no logotipos de Ramaldi.
